# CubaPlus Web App — V1

Prototipo profesional móvil-first de una membresía digital.

Incluye:
- Landing page
- Planes $3/$5/$10
- Checkout preparado para CuboPay
- Login UI
- Área visual de beneficios
- Responsive Android
- Documento de integración segura para backend/webhook

Importante: esta entrega es un frontend funcional/prototipo. El pago real, autenticación, base de datos y webhook requieren un backend y las credenciales/endpoint de CuboPay.

Para ejecutar:
npm install
npm run dev
